# Contributing to Employee Management System

Thank you for your interest in contributing to this project.

I welcome contributions that help improve the Employee Management System application and its documentation.

## How to Contribute

### 1. Fork the Repository

Create your own copy of the repository by clicking the **Fork** button on GitHub.

### 2. Clone the Repository

```bash
git clone https://github.com/Aiden-Vihaan/employee-management-system.git
```

### 3. Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

### 4. Make Changes

Add your improvements, bug fixes, or new features.

### 5. Commit Your Changes

```bash
git commit -m "Add your meaningful commit message"
```

### 6. Push to GitHub

```bash
git push origin feature/your-feature-name
```

### 7. Open a Pull Request

Submit a Pull Request describing your changes.

---

## Contribution Guidelines

- Write clean and readable code
- Follow project folder structure
- Test changes before submitting
- Keep commits meaningful
- Update documentation if needed

---

## Reporting Issues

If you find bugs or have suggestions, feel free to open an issue in the repository.
